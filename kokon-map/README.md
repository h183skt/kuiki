# 古今マップ（kokon-map）

東京・神奈川を中心に、**古地図・過去の空中写真・現在の地図**を年代スライダーで切り替えて見比べる地図ビューアです。

ビルド不要の **単一 HTML ファイル**（`index.html`）だけで動きます。ブラウザで開くか、GitHub Pages に置くだけで公開できます。

---

## できること

| 機能 | 内容 |
| --- | --- |
| 年代スライダー | 1880年代の迅速測図 → 1936年 → 1945年 → … → 最新写真 → 現在の地図 を、スライダーや ◀ ▶ ボタン、左右キーで切り替え |
| レイヤーパネル | 20種類の地図・写真から、メインの地図を自由に選択 |
| 濃さ（不透明度） | 古い写真を薄くすると、下に敷いた淡色地図（現在の街）が透けて重なる |
| 重ねる | 陰影起伏図・色別標高図・傾斜量図・明治期の低湿地・現在の地図を半透明で重ね合わせ |
| 左右スワイプ比較 | 画面を左右に分割し、分割線をドラッグして2つの年代を直接見比べ |
| 地名・住所検索 | 国土地理院の地名検索APIで移動（例：「横浜駅」「鎌倉市由比ガ浜」） |
| 東京・神奈川クイックジャンプ | 東京12か所・神奈川12か所へワンタップ移動 |
| 現在地 | 端末のGPSで現在地へ移動 |
| URL共有 | 表示中の位置・ズーム・レイヤーがURLに入るので、そのまま共有できる |
| レイヤー動作確認 | 表示中の地点で各レイヤーのタイルを1枚ずつ読み込み、○ / × で配信状況を確認 |

## 使い方

### そのまま開く

`index.html` をダウンロードして、ブラウザにドラッグするだけで動きます（インターネット接続は必要です）。

### GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/kokon-map/` で公開されます

`index.html` がリポジトリ直下にあるので、ワークフローの設定は不要です。

### スマホで使う

公開したURLをスマホで開き、ブラウザの「ホーム画面に追加」をすると、アプリのように全画面で使えます。

## 操作のコツ

- **年代の行き来** … 画面下のスライダーを動かすか、キーボードの `←` `→`
- **昔と今を重ねる** … 古い写真を選び、レイヤーパネルの「濃さ」を 50% くらいにする
- **地形と重ねる** … 「重ねる」で *陰影起伏図* をオンにすると、埋め立て前の地形が読み取りやすい
- **低地を確認する** … 「重ねる」で *色別標高図* や *明治期の低湿地* をオンにする
- **並べて比較** … 上部の「比較」ボタン → 分割線の丸いつまみを左右にドラッグ

## 出典・利用条件

このアプリはタイル画像を配信元のサーバーから直接読み込みます。利用の際は各配信元の規約に従ってください。

- **地理院タイル**（標準地図・淡色地図・白地図・各年代の空中写真・明治期の低湿地・陰影起伏図・色別標高図・傾斜量図）
  国土地理院 <https://maps.gsi.go.jp/development/ichiran.html>
- **迅速測図**（1880年代・関東平野）
  農研機構 歴史的農業環境閲覧システム <https://habs.rad.naro.go.jp/>
- **OpenStreetMap**
  © OpenStreetMap contributors <https://www.openstreetmap.org/copyright>
- **地名・住所検索**
  国土地理院 地名検索API <https://msearch.gsi.go.jp/>
- **Leaflet 1.9.4**（BSD-2-Clause） <https://leafletjs.com/>

大量アクセスは配信元の負荷になります。自動巡回やタイルの一括ダウンロードには使わないでください。
