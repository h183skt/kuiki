# プロジェクト特有のルール

## バージョン管理とブランチ運用ルール
* **開発用ブランチとバージョン**:
  * `main` ブランチが `v1.9.8` の間、開発用ブランチは `v1.9.8.001` から開始し、修正ごとに `v1.9.8.002`, `v1.9.8.003`... のようにカウントアップしてブランチ名およびコード内のバージョン表記（`webapp.gs` の `VERSION` 定義）を細かく管理してください。
* **コミットメッセージルール**:
  * コミットメッセージの先頭には、必ず `[vX.Y.Z]` または `[vX.Y.Z.NNN]` のように、そのコミット時点でのバージョン情報を付与してください（例：`[v1.9.8.001] アカウント切り替えボタンを非表示に変更`）。
* **メイン反映（マージ）時**:
  * ユーザーから「メインに反映してください」と指示があった場合、バージョンを `v1.9.9` として `webapp.gs` の `VERSION` 定義を更新し、`main` ブランチにマージしてください。
